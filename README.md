# Decision support model for Crisantemo Bakery in Uruguay

Multi-criteria analysis web application developed for a bakery in Uruguay that prioritizes which products are most worth producing.

### Main idea:
Replace intuition-based decision making with a quantitative analysis that shows which products are most convenient based on economic, production and commercial factors.


### Technologies used:
- Python + FastAPI
- SQLite
- Pytest
- React
- JavaScript
- Vite
- Recharts
- Vercel + Render


### Architectural aspects:
- REST API-based backend, separate from the frontend
- Criteria weighting with AHP, CRITIC and Entropy
- Product ranking with TOPSIS and sensitivity analysis
- Scenario evaluation: regular, special and new products
